# MicroWars ステージ設計(全30ステージ)

舞台は「反応槽(活性汚泥)」の中に固定し、運転状態・時間帯・槽の形式・フロックの深さを変えて30ステージを構成する。
略称: 【運転状態】=A、【フロック探検】=B、【時間帯・季節】=C、【槽形式】=D

## 備考
- 主要ギミック: 流れ(押し流し)、曝気(回復/加速)、DO低下(好気性弱体化)、スカム(水面戦)、薬品(継続ダメージ)、汚泥返送(増援)、逆洗(押し戻し)。
- 各ステージの数値(HP・攻撃・コスト・ウェーブ)は、MVP実装後にデータ駆動(JSON/TS)でバランス調整する。
- 世界観のトーン(コミカル/リアル)は未決定。
